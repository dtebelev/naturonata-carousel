# 📸 Naturonata Carousel Generator

Генератор Instagram-каруселей для бренда Naturonata.

## Деплой на Streamlit Community Cloud

Приложение задеплоено на [share.streamlit.io](https://share.streamlit.io).

## Локальный запуск

```bash
pip install -r requirements.txt
playwright install chromium
python -m streamlit run app.py
```
